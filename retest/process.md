# Honest Tape 重測系列：流程

寫於 2026-10-18。呢份係流程，唔係某一個策略嘅預先登記；每集策略另外用 [`plan_template.md`](plan_template.md) 寫計劃，commit 入呢個 repo 之後先跑。

---

## 0. 目的同範圍
* 系列內容：將其他 backtest 頻道**公開講過嘅規則**，寫成 code，
  放落恒指用十幾年數據、扣真實成本、同隨機基準比較、做多重測試校正，再出判決。
* 只測規則，唔評論人。原片用自己說話轉述，附連結；唔用原片片段、截圖、thumbnail。
* 方法說明：[`../methodology.md`](../methodology.md)（方法片同每集判決都跟佢）。
* 目標：每集人手時間（唔計錄音剪片）大約 1–2 個鐘；其餘自動。
* 唔做：自動落單、自動發佈、自動解鎖驗證期 / holdout、自動決定含糊規則。

## 1. 流程同人手關卡
```
R0 搵候選 ──► R1 抽規則 ──► 【閘 A：我拍板含糊位】
   ──► R2 寫計劃 ──► 【閘 B：我批准 → commit】
   ──► R3 數據 ──► 【閘 C：要付費就先報價，我確認】
   ──► R4 寫 code + pytest + 獨立覆核
   ──► R5 跑 dev ──► R6 按計劃出 dev 判決
   ──► 【閘 D：dev 合格先問我解唔解鎖 val】 ──► R7 跑 val
   ──► R8 起稿 ──► 【閘 E：人手審稿、發佈】
系列層面：【閘 F：holdout 只喺我明確解鎖時，全系列一次過跑】
```

| 閘 | 人手做咩 | 點解唔可以自動 |
|---|---|---|
| A | 決定含糊規則點定義；有幾種合理寫法就全部列做變體 | 呢個係研究決定，唔係技術問題 |
| B | 批准計劃，commit；commit hash 記入系列帳簿 | 「先登記、後跑」嘅證據 |
| C | 睇報價、確認先下載 | 付費數據一律先報價 |
| D | 解鎖 val（每個策略只可以用一次） | 數據分割規則 |
| E | 審稿、錄音、按掣發佈 | 用我個名同品牌講嘢 |
| F | 解鎖 holdout | 只可以用一次，而且係全系列共用 |

另外：**睇完結果之後發現 bug**，要停低問我，確認係 bug 唔係調參，先修，並寫入該集計劃「修 bug 紀錄」。

### 各步自動做咩
* **R0**：每星期自動掃參考頻道新片，
  按「規則明唔明確」「時間框架有冇數據」排序，出候選清單。我揀一條。
* **R1**：讀字幕（冇字幕就要我補資料），將規則拆成「明確」同「含糊」兩欄，
  每個含糊位提出 1–3 種寫法，標明邊個最貼原意。
* **R2**：用 `plan_template.md` 起草，填好規則、變體、合格標準、預測。
* **R4**：寫 code，重用形態研究嘅事件、交易同多重測試模組。
  加單元測試：每條規則最少一個人手砌嘅小例子（已知答案）。再由一個冇睇過 code 嘅獨立覆核，對照計劃檢查規則。
* **R5 / R6**：判決照計劃機械式計，唔加主觀判斷。報告寫入該集計劃「結果」，更新系列帳簿。
* **R8**：自動起草劇本同圖表，停低等人手審稿，永遠唔會自己發佈。

## 2. 數據同時期
| 市場 | 用途 | dev | val | holdout |
|---|---|---|---|---|
| 恒指日線（Yahoo `^HSI`，同 P1） | **主判決** | 1987-01 至 2012-12 | 2013-01 至 2019-12 | 2020-01 起（鎖住） |
| ES / NQ 日線（Databento） | 原市場對照（描述性，唔用嚟判決） | 2010-06 至 2020-12 | 唔用 | 唔用 |

* 恒指時期同 P1 一樣，咁兩個研究可以直接比較。根據 P1 紀錄，恒指**指數層面**冇形態入過 val，
  所以恒指 2013–2019 對呢個系列仲係未用過；港股成份股 val 已經喺 P1 用過兩個三角形。
* ES / NQ：日線研究嘅驗證期 2021–2024 已經用咗、holdout 2025 起鎖住，所以只用 dev 做原市場對照，報告講明係描述性。
* **日內策略（5 分鐘、15 分鐘、1 小時）**：而家冇恒指期貨分鐘數據。呢類候選標「要數據」，暫時擱置；
  搵到來源之後先報價，我確認先買。4 小時策略同樣擱置（唔可以用日線假扮）。
* 恒指係價格指數，冇股息；交易當作經盈富基金（2800）做。

## 3. 成本
* 預設：同 P1 一樣，恒指經 2800，每邊約 0.109%（佣金 0.08% + 徵費 / 交易費約 0.0086% + 滑價 0.02%），用 `patterns.trading.cost_side("HSI", …)`。
* 敏感度：0 成本、0.5 倍、2 倍。
* 恒指期貨 / 小型恒指版本：**未定**。第一次用之前要按我實際券商收費寫入計劃（每張每邊佣金、交易所費用、1 tick 滑價）。

## 4. 評估（每集一樣）
1. **原片規則照做**：教科書 / 原片講嘅入場、止蝕、目標、持有時間。
2. **隨機基準**：同 P1 第 9 節第 7 點，同一市場、同一時期、同持有日數、同方向隨機入場 1,000 次；
   報「策略 − 隨機」同 t 值。另報「同一段時間一直持有」做 beta 對照。
3. **「100 單」對照**：由 dev 交易隨機抽 100 單連續樣本，報結果分佈嘅 5%–95% 範圍，
   示範 100 單結論有幾唔穩定（呢個係描述性，唔影響判決）。
4. **多重測試**：
   * 每集家族 = 該集所有變體；
   * **系列家族 = 系列累計所有策略 × 變體**（帳簿 `series_ledger.md`）；
   * 每集都用累計家族重新計 White RC、Hansen SPA，DSR 試驗數 N = 累計總數；兩個家族都報。

## 5. 判決對應（預設，每集計劃可以收緊但唔可以放寬）
| 判決 | 條件 |
|---|---|
| **KO**（冇 edge） | 所有變體未扣成本「策略 − 隨機」t < 2.0，或者過咗 t 但未扣成本版本過唔到多重測試（運氣範圍） |
| **判數輸**（有 edge 被成本食晒） | 最少一個變體未扣成本 t ≥ 2.0 而且過多重測試，但扣成本後唔合格 |
| **過咗 dev（未判）** | 扣成本後過晒 dev 標準 → 等閘 D |
| **等 holdout** | 過埋 val → 等全系列 holdout（閘 F） |
| **企得住** | 只可以喺 holdout 過咗之後先用 |

* 按頻道定義，「企得住」要扣成本過 holdout。holdout 係全系列共用、只用一次，所以**單集最多只可以講到「等 holdout」**，
  片入面要照講，唔可以提早叫「企得住」。
* dev 合格標準（預設）：
  1. 未扣成本「策略 − 隨機」t ≥ 2.0；
  2. 扣成本後每筆平均淨回報 > 0，而且扣成本「策略 − 隨機」t ≥ 2.0；
  3. 系列累計家族 White RC p < 0.10，**或者** DSR ≥ 0.95。
* val 確認（預設）：同方向、扣成本淨回報 > 0、「策略 − 隨機」t ≥ 1.5。
